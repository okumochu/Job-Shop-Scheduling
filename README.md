## Historical project

Originally developed in 2024, this educational project explored genetic algorithms and NSGA-II for job shop scheduling. Its implementation files, datasets, and figures are now maintained together with the flexible job shop examples in the combined repository.

This repository now serves as a historical reference and redirect. Development here has concluded.
